# 飞书多维表格前端插件

这是一个用于飞书多维表格的前端插件，可以读取表格数据并根据自定义模板生成格式化输出。

## 功能特性

- 🚀 **数据读取**: 从飞书多维表格读取数据
- 📝 **模板编辑**: 支持自定义模板，使用 `[字段名]` 格式引用字段
- 🔍 **数据筛选**: 自动筛选环境为"生产"的数据
- 📊 **分组展示**: 按照指定字段分组展示数据
- 🎨 **Markdown支持**: 模板支持Markdown格式
- 🎯 **演示模式**: 无需配置即可测试功能

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 访问应用

打开浏览器访问 `http://localhost:5173`

## 使用说明

### 演示模式

无需填写任何配置信息，直接点击"生成结果"按钮即可使用演示数据测试功能。

### 正式使用

1. **获取飞书应用凭证**:
   - 在飞书开放平台创建应用
   - 获取 App ID 和 App Secret
   - 开通多维表格权限

2. **获取表格信息**:
   - 打开目标多维表格
   - 获取 App Token（从URL中提取）
   - 获取 Table ID（从表格设置中查看）

3. **配置插件**:
   - 在配置面板填写相关信息
   - 编辑模板内容
   - 点击"生成结果"

## 模板语法

### 基本语法

使用 `[字段名]` 格式引用数据表中的字段：

```
[数据中心]：
  [系统]、[项目名称]、[需求FLOW]、[任务内容]、[开发负责人]、[上线类型]
```

### 高级语法

支持Markdown格式和自定义样式：

```
**[数据中心]：**
  <text_tag color='red'>[系统]</text_tag> [项目名称]：[需求FLOW]、[任务内容]、[开发负责人]、*[上线类型]*
```

### 分组规则

- 第一行的 `[字段名]` 将作为分组字段
- 数据会按照该字段的值进行分组
- 每组内会列出所有相关记录

## 数据要求

数据表必须包含以下字段（或您在模板中引用的字段）：
- 数据中心
- 系统
- 项目名称
- 需求FLOW
- 任务内容
- 开发负责人
- 上线类型
- 环境（用于筛选"生产"环境数据）

## 开发

### 项目结构

```
src/
├── components/          # React组件
│   └── FeishuPlugin.tsx # 主插件组件
├── services/           # API服务
│   └── feishu.ts       # 飞书API服务
├── utils/              # 工具函数
│   ├── templateProcessor.ts # 模板处理
│   └── mockData.ts     # 演示数据
└── App.tsx            # 应用入口

```

### 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **Markdown**: marked
- **HTTP客户端**: axios

### 可用脚本

- `npm run dev` - 启动开发服务器
- `npm run build` - 构建生产版本
- `npm run preview` - 预览构建结果
- `npm run check` - 运行TypeScript类型检查

## 注意事项

1. **环境筛选**: 系统会自动筛选环境字段等于"生产"的数据
2. **字段匹配**: 模板中的字段名必须与数据表中的字段名完全一致
3. **API限制**: 注意飞书API的调用频率限制
4. **数据安全**: 妥善保管 App Secret，不要在前端代码中硬编码
